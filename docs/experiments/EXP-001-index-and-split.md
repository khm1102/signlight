# EXP-001. 데이터 인덱스와 근접 중복 그룹 분할

- 날짜: 2026-11-22
- 코드: `src/signlight/data.py` (이 문서와 같은 커밋), 실행 `uv run python -m signlight.data --thr 20`
- 설정: dHash 16×16(256bit), 해밍 임계값 20, 군집은 클래스별 union-find, 분할은 `StratifiedGroupKFold(n_splits=5, shuffle=True, random_state=42)`의 fold 0 = test, fold 1 = val
- 결과 파일: `results/split_stats.json`, `data/processed/index.csv`(git 제외)

## 목적
Kaggle ASL Alphabet은 연속 프레임이라 거의 같은 이미지가 많다. 같은 장면이 train과 test에 동시에 들어가면 정확도가 부풀려지므로, 근접 중복을 군집으로 묶고 군집 단위로 분할한다.

## 결과
| 항목 | 값 |
|---|---|
| 이미지 | 72,000 (24 클래스 × 3,000) |
| split | train 43,449 (60.3%) / val 14,308 (19.9%) / test 14,243 (19.8%) |
| 군집 수 | 전체 3,160, 클래스당 32(D) ~ 426(W) |
| 최대 군집 | 클래스 내 최대 1,000장(33.3%; A, B) |

클래스별 split 비율은 군집이 큰 클래스에서 많이 흔들린다(예: K test 7%, B test 33%). 전체 비율은 목표와 맞는다.

## 해석
- 최대 군집이 1,000장(= 클래스의 정확히 1/3)인 클래스가 많다. 클래스마다 약 1,000프레임씩 3번 촬영한 구조로 보이고, 한 번 찍은 묶음이 통째로 한 군집이 된 것으로 추정한다 `[미확인]`.
- 그래도 군집 경계 바로 바깥의 비슷한 프레임(해밍 거리 21~25)은 다른 split에 들어갈 수 있다. 사전 측정에서 이미지의 99.5%가 해밍 거리 25 이내에 다른 이미지를 갖고 있었다.
- 촬영자와 배경이 하나라는 점은 분할로 해결할 수 없다.

## 한계
**Kaggle 내부 val/test 정확도는 여전히 낙관적이다.** 주 결론은 합성 변형셋(EXP-003, 004)과 직접 촬영셋(EXP-006)에서 낸다.
