# EXP-005. 오류 분석과 개선 실험(CLAHE), 대표 모델 선정

- 날짜: 2026-11-22
- 코드: `src/signlight/landmarks.py`(`clahe`, `HandDetector(preprocess="clahe")`), `src/signlight/rf.py --clahe`(이 문서와 같은 커밋)
- 결과 파일: `results/preds/rf_geom_clahe__synth__*.npz`
- 기준 데이터: 합성셋 2,400장(test split에서 클래스당 100장)

## 1. 혼동 분석 (합성 clean)
| 모델 | 가장 많이 틀린 쌍(정답→예측, 비율) | 가장 낮은 클래스 |
|---|---|---|
| rf_geom | D→O 0.23, R→U 0.13, N→M 0.09, V→U 0.05, A→M 0.05 | H 0.14, X 0.23, Q 0.24, A 0.45, D 0.57 |
| cnn_plain(시드 3개 합산) | H→G 0.92, X→S 0.81, G→H 0.66, S→X 0.52, L→T 0.50, N→M 0.48 | H 0.01, N 0.02, E 0.11, S 0.12 |
| cnn_aug(시드 3개 합산) | H→G 1.00, G→H 0.74, S→X 0.59, X→R 0.55, I→K 0.48, V→K 0.47 | H 0.00, N 0.04, I 0.14, X 0.17 |

- **RF의 최하위 클래스(H, X, Q)는 분류가 아니라 검출 실패 때문이다.** H는 100장 중 81장이 검출 실패였고, 검출된 19장 중 14장은 맞혔다.
- 검출률이 **split마다 크게 다르다**(`results/detection_rate.csv`). H는 train 98.2%, val 68.9%, **test 17.9%**다. X는 test 16.3%, Q는 test 21.6%다. 그룹 분할로 한 번에 찍은 묶음이 통째로 test에 갔고, 그 묶음이 검출하기 어려운 촬영(역광이나 손 잘림, EXP-002)이었다. **test split 자체에 "다른 촬영 회차"라는 환경 변화가 섞여 있다.**
- RF의 실제 분류 오류는 모양이 비슷한 쌍에서 난다. D→O(엄지와 손가락 끝이 닿는 둥근 모양), N→M(엄지 아래 손가락 수), R→U, V→U(검지·중지 겹침 여부)다.
- CNN은 **H↔G**(옆으로 가리키는 손, 손가락 1개와 2개의 차이)와 **S↔X**를 거의 구분하지 못한다. 손가락 개수처럼 작은 차이를 구도 단서가 덮어 버리는 것으로 본다 `[추정]`.

## 2. CLAHE 전처리 (RF 검출 개선 시도)
학습된 rf_geom에, 검출 전에 CLAHE(LAB의 L 채널, clipLimit 2.0, 8×8)를 적용해 추출한 관절을 넣었다.

| 조건 | 검출률 기본 → CLAHE | e2e 정확도 기본 → CLAHE |
|---|---|---|
| clean | 0.767 → 0.599 | 0.717 → 0.551 |
| dark_0.5 | 0.252 → 0.116 | 0.193 → 0.094 |
| dark_0.25 | 0.073 → 0.018 | 0.047 → 0.010 |
| clutter | 0.511 → 0.383 | 0.421 → 0.308 |
| shift | 0.610 → 0.468 | 0.518 → 0.395 |
| scale_small | 0.756 → 0.709 | 0.703 → 0.652 |
| scale_large | 0.563 → 0.381 | 0.450 → 0.293 |

- **모든 조건에서 나빠졌다.** 어두운 조건의 Drop을 5%p 이상 줄인다는 채택 기준을 만족하지 못해 **기각**한다.
- 원인 추정: 어두운 합성 이미지에는 센서 노이즈(σ=6)가 들어 있는데, CLAHE가 이 노이즈를 같이 증폭한다. 또 원본의 역광 실루엣(EXP-002)은 손 안쪽 디테일이 없어서, 대비를 올려도 손 모양이 살아나지 않는다 `[추정]`.

## 3. 대표 모델 선정 (보고서 본문용)
| 쪽 | 선택 | 근거 |
|---|---|---|
| 관절 | **rf_geom** | DT보다 모든 조건에서 3~4%p 높다. norm 특징보다 높다. CLAHE는 기각. 좌우 정렬은 정확도 차이가 없지만 왼손 사진에 대비해 쓴다(EXP-003) |
| 이미지 | **cnn_aug**(본문), cnn_plain(비교) | 합성 7개 조건 평균 정확도가 aug 0.408, plain 0.244다. clean은 plain이 높으므로 둘 다 보고한다 |

## 한계
- CLAHE 외의 밝기 보정(감마, 히스토그램 평활화)은 시험하지 않았다.
- test split의 검출률 편차는 촬영 회차 효과로 해석했지만, 회차 라벨이 없어 직접 확인하지는 못했다 `[미확인]`.
