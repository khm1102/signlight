## 실패 유형 (`reports/figures/exp002_failures.png`, 24장을 눈으로 분류)
1. **역광 실루엣**: 밝은 창과 벽을 배경으로 손이 검게 찍힌 경우(A, E, N, O, W). 원본 자체가 "어두운 손" 조건에 가깝다.
2. **손이 화면을 꽉 채우거나 가장자리에서 잘림**: 손목이나 팔이 안 보이고 손이 화면 밖으로 나감(A, G, P, N).
3. **손가락이 겹친 주먹형**: M, N, S, E처럼 손가락 끝이 가려지는 모양.

## 결정
- **`DET_CONF = 0.3`, `DET_PAD = 0.0`(기존 값 유지).** 검출률이 가장 높다.
- 여백(pad)은 잘린 손에 도움이 될 것으로 예상했지만 오히려 검출률을 낮췄다. 손이 작아져서 생긴 손실이 더 크다고 본다 `[추정]`.
- 역광 실패는 Task 13(EXP-005)의 CLAHE 전처리 실험 대상이다.

## 해석과 한계
- 검출률이 약 83%이므로, 깨끗한 Kaggle 이미지에서도 RF의 e2e 정확도 상한은 약 83%다.
- 오른손 판정 94.5%는 플랜의 기준(95%)보다 조금 낮다. 전체 데이터 측정(Task 6)에서 다시 보고, 좌우 정렬을 쓸지 말지는 EXP-003에서 둘 다 비교해 정한다.
- 1차 측정(2026-11-22, 20장 × 24클래스, 전체 train/val/test에서 무작위)은 78.3%였다. 표본 차이로 보고, 최종 수치는 Task 6의 전체 추출로 확정한다.
