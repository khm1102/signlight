# EXP-003. RF/DT 학습과 합성 변형 평가

- 날짜: 2026-11-22
- 코드: `src/signlight/rf.py`(이 문서와 같은 커밋), 실행 `uv run python -m signlight.rf`
- 데이터: `index.csv`(EXP-001 분할), `landmarks.npz`(EXP-002 설정 conf 0.3, pad 0)
- 학습: train split 중 **검출된 행만** 사용. 하이퍼파라미터는 val(검출 행)에서 선택
  - RF: n_estimators 300, `max_depth ∈ {None, 20}` × `min_samples_leaf ∈ {1, 3}`
  - DT: `max_depth ∈ {None, 10, 20}`
  - 시드 42
- 평가: e2e(검출 실패 = 오답, 분모 = 전체). 합성셋은 test split에서 클래스당 100장(총 2,400장) × 7조건이고, 변형 key는 index 행 번호다.
- 결과 파일: `results/preds/{rf_geom,dt_geom,rf_norm,rf_geom_nocanon}__*.npz`, `results/rf_train_log.json`, `results/logs/rf.log`

## 해석
1. **RF의 손실은 대부분 검출 실패에서 나온다.** clean에서 검출된 것만 보면 93.4%를 맞히지만, 검출률이 76.7%라 e2e는 71.7%다. 어두움(dark_0.5)에서는 검출률이 25%로 떨어져 e2e가 19%까지 내려간다.
2. 검출이 돼도 변형 조건에서는 분류 정확도가 같이 떨어진다(dark_0.5 76.8%, clutter 82.3%). 관절 좌표 자체가 부정확해지는 것으로 본다 `[추정]`.
3. **크기 축소(scale_small)에는 거의 영향이 없다**(Drop 1.4%p). 좌표 정규화가 작동한다. 반면 이동(shift)과 확대(scale_large)는 손이 화면 밖으로 잘리면서 검출이 떨어진다.
4. **RF > DT**: 모든 조건에서 RF가 3~4%p 높다. **geom > norm**: clean 기준 2.5%p 높다(검출된 것만 보면 93.4% vs 90.2%).
5. **좌우 정렬 유무 차이는 없다**(0.717 vs 0.718). Kaggle은 거의 한 손이라 영향이 없다. 직접 촬영셋에 왼손 사진이 들어올 수 있으므로 **주 모델은 정렬을 쓰는 rf_geom으로 한다**.
