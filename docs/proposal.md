# 기획안 (원본: 인공지능 기말 프로젝트 기획안 PPT, 2026-11-13 발표, 팀 '손전등')

> 원본 PPT의 내용을 텍스트로 옮겼다. 원본과 달라진 부분은 **[변경]**으로 표시했다.

## 주제
수어 알파벳 인식에서의 AI 모델 성능 비교. CNN과 Random Forest가 촬영 환경이 바뀔 때 얼마나 안정적으로 인식하는지 분석한다.

## 연구 질문
이미지를 직접 학습하는 CNN과 손 관절 좌표를 쓰는 머신러닝 모델 중, 어떤 방식이 촬영 환경 변화에 더 강한가?

## 목적
1. 두 가지 입력 방식(픽셀, 손 관절 좌표)의 수어 알파벳 분류 성능을 비교한다.
2. 촬영 환경 변화에 따른 정확도를 분석한다.
3. 실제 환경에서 모델별 장단점을 파악한다.

## 데이터
- Kaggle ASL Alphabet (`grassknoted/asl-alphabet`): 약 87,000장, 200×200, 29개 클래스(A~Z, del, nothing, space)
- **[변경]** 대상 클래스: 기획안에는 6개(A, B, C, L, V, Y)였으나 **J·Z를 제외한 정적 알파벳 24개**로 확대했다(2026-11-22).
- 움직임이 필요한 J, Z는 제외한다.
- 팀원이 직접 찍은 이미지를 별도 테스트 데이터로 쓴다.
- MediaPipe의 손 관절 검출 실패 사례를 따로 분석한다.

## 모델
| | 모델 A: CNN | 모델 B: Random Forest |
|---|---|---|
| 입력 | 이미지 픽셀 | MediaPipe 손 관절 21개 좌표 |
| 절차 | 이미지 입력 → 크기 조정·전처리 → CNN 학습 → 예측 | 이미지 입력 → 관절 21개 추출 → 좌표 정규화(손목 위치, 손 크기 기준) → RF 학습 → 예측 |
| 도구 | Python, TensorFlow/Keras | Python, MediaPipe, scikit-learn |
| 예상 약점 | 촬영 환경에 따라 성능이 흔들릴 수 있음 | 관절 검출 정확도에 성능이 좌우됨 |

보조 모델: Decision Tree로 RF와 성능 차이를 확인한다.

## 실험 (촬영 환경)
| 실험 | 조건 | 목적 |
|---|---|---|
| 1 | 일반 조명 (밝고 단순한 배경) | 기준 정확도 |
| 2 | 어두운 조명 | 조명 영향 |
| 3 | 복잡한 배경 | 배경 영향 |
| 4 | 손 위치·크기 변화 | 안정성 |

- 평가 지표: Accuracy, Confusion Matrix, Accuracy Drop(일반 환경 대비 감소 폭. 가장 중요한 지표)
- 두 모델은 동일한 테스트 이미지로 평가한다.
- RF에서 손 관절 검출에 실패한 경우는 인식 실패로 계산한다.

- 머신러닝 모델의 실생활 적용 가능성과 한계를 확인한다.
