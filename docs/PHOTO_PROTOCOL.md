# 직접 촬영 테스트셋 안내 (팀원용)

모델이 실제 환경에서도 잘 맞히는지 보려고, 팀원이 직접 찍은 사진으로 평가한다. 학습에는 쓰지 않는다.

## 무엇을 찍나
- **글자 24개**: A B C D E F G H I K L M N O P Q R S T U V W X Y (J, Z는 움직임이 필요해서 제외)
- **환경 4가지** × **한 사람당 글자마다 2장**
- 팀원 4명 기준 총 4 × 24 × 4 × 2 = **768장**(한 사람당 192장)

| 폴더 | 환경 | 찍는 방법 |
|---|---|---|
| `normal` | 일반 조명 | 밝은 실내, 흰 벽이나 단색 배경, 손이 화면 가운데 |
| `dark` | 어두운 조명 | 방 불을 끄고 모니터나 스탠드 정도의 빛만 둔 상태 |
| `complex_bg` | 복잡한 배경 | 물건이 많은 책상이나 책장 앞 |
| `position` | 손 위치·크기 변화 | 손을 화면 구석에 두거나, 멀리서 찍어 손이 작게 나오게 |

## 찍을 때 지킬 것
- 손 전체(손목 포함)가 화면 안에 들어오게 한다.
- 정지 자세로 찍는다. 흔들려 흐린 사진은 다시 찍는다.
- 기본은 **오른손**이다. 왼손으로 찍었다면 파일명 끝에 `_L`을 붙인다.
- 세로·가로 사진 모두 괜찮다. 아이폰 HEIC 그대로 넣어도 된다.
- 수어 모양은 Kaggle 데이터 예시(`data/raw/asl_alphabet/test/{글자}_test.jpg`)와 같게 한다.

## 폴더와 파일 이름
```
data/custom_test/
  normal/
    A/  khm_1.jpg  khm_2.jpg  lhn_1.jpg ...
    B/  ...
  dark/
  complex_bg/
  position/
```
- 파일명은 `{이니셜}_{번호}.jpg` 형식이다. 예: `khm_1.jpg`, `ich_2_L.HEIC`
- 폴더 이름은 위와 **정확히** 같아야 한다. 글자 폴더는 대문자 한 글자다.

## 넣은 뒤 확인
```bash
uv run python -m signlight.custom_test check
```
폴더 이름이 틀리면 어떤 폴더가 문제인지 알려 준다. 칸마다 몇 장인지, 목표(칸당 8장)에 못 미친 칸이 어디인지도 출력한다.

사진은 개인 얼굴이나 방이 찍힐 수 있으니 git에 올리지 않는다(`.gitignore` 처리돼 있음).
